# CAD

## Structure
- `assemblies/` — full arm assembly files
- `parts/` — individual printed part files
- `exports/` — STEP/STL exports for viewing without SolidWorks (or your
  friend's CAD software of choice)

## Notes
- If CAD is being actively worked on in Onshape or another cloud tool,
  periodically export finished versions here so this repo stays the
  single source of truth for the project.
